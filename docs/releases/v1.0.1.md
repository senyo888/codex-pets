# Codex Pets v1.0.1 — Security maintenance

This maintenance release updates the image tooling, bounds contributed image
processing, and adds secret scanning. The catalogue contains eight desktop v2 pets.

## Security fixes

- Upgrade the development and CI dependency to Pillow 13.0.0, the first patched
  version for all 41 Pillow Dependabot alerts recorded on 2026-10-31.
- Bound contributed image files, preview frame counts, canvas dimensions, and header
  resize dimensions before expensive image processing. Preserve the six-frame idle
  timing and reduced-motion still checks.
- Add Gitleaks 8.30.1 checks for Git history and public working files, locally and in
  CI, with redacted output and a checksum-verified CI binary.
- Add regression coverage for malformed GIFs, oversized canvases, animated static
  inputs, and valid PNG/WebP rendering.

## Other changes since v1.0.0

- Add Áureo as pet 008, preserving its original atlas and the documented
  [exact-asset maintainer exception](https://github.com/senyo888/codex-pets/blob/v1.0.1/docs/VALIDATION_EXCEPTIONS.md#aureo-008).
  Its recorded chroma, edge and left-direction limitations remain visible in QA.
- Align public idle previews with the 6.6-second desktop cadence and provide
  matching static PNG alternatives for reduced motion.
- Clarify installation and package documentation, and pin the historical v1.0.0
  release header to its immutable release assets.

## Updating

Developers should reinstall `requirements-dev.txt` in their Python 3.12+ environment
and install Gitleaks 8.30.1. See the
[maintenance instructions](https://github.com/senyo888/codex-pets/blob/v1.0.1/docs/MAINTENANCE.md).

The security patch leaves pet artwork, metadata, hashes, installer links, and the v2
sprite and catalogue formats unchanged. Existing pets do not need reinstallation.

[Compare v1.0.0 with v1.0.1](https://github.com/senyo888/codex-pets/compare/v1.0.0...v1.0.1).
